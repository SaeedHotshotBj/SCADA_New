> نسخه‌ی مستندشده: شاخه‌ی `backend-integrated`، کامیت `1be52d90624ebb2dbb4ecf5543b4e80519bb6746`
>
> تاریخ برداشت ساختار: ۲۵ نوامبر ۲۰۲۶

این مستندات از روی کد همین کامیت تهیه شده‌اند. هدف، شرح رفتار پیاده‌سازی‌شده‌ی فعلی است؛ نه شرح معماری‌ای که هنوز ساخته نشده است.

## وضعیت واژگان در مستندات

- **پیاده‌سازی‌شده:** کد یا مسیر اجرایی آن در نسخه‌ی مبنا وجود دارد.
- **محدودیت فعلی:** قابلیت وجود دارد، اما دامنه یا شرایط استفاده‌ی آن محدود است.
- **پیشنهاد آینده:** ایده یا مسیر توسعه است و نباید به‌عنوان قابلیت موجود در نظر گرفته شود.

## نمای یک‌خطی پروژه

SCADA_New یک برنامه‌ی وب فارسی و راست‌به‌چپ برای مدیریت اطلاعات کارخانه، تجهیزات و تگ‌ها، نمایش زنده و HMI، داده‌ی تاریخی، آلارم، تولید، بچ/توزین، کیفیت، برنامه‌ریزی، گردش‌کار و گزارش است. رابط مرورگر با JavaScript ES Modules نوشته شده و API آن با FastAPI و SQLite اجرا می‌شود.

## اصل مهم درباره‌ی وضعیت فعلی

در نسخه‌ی مستندشده:
- پایگاه داده‌ی اصلی **SQLite** است.
- تاریخچه‌ی تگ‌ها در جدول `telemetry_samples` ذخیره می‌شود.
- پریود پیش‌فرض تاریخچه‌ی PLC برابر `5 s` و Retention پیش‌فرض برابر ۳۰ روز است.
- TimescaleDB، ClickHouse، تجمیع پیوسته‌ی دقیقه‌ای/ساعتی و سیاست On-Change مستقل برای هر تگ در این کامیت پیاده‌سازی نشده‌اند.
- HMI یک مسیر WebSocket برای تازه‌سازی نما دارد؛ داده‌ی لایو یک‌ثانیه‌ای نمودار HMI با تاریخچه‌ی پایدار دیتابیس یکسان نیست.

جزئیات و پیشنهادهای توسعه در اسناد داده و مقیاس‌پذیری آمده‌اند.
